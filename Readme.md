# Ocean Eye - Oil Spill Intelligence Platform

A comprehensive, real-time oil spill monitoring and intelligence system with Google Authentication and multi-language support.

## Features

### Dashboard
- Real-time maritime vessel tracking
- Live weather data (wind, wave, temperature)
- AI confidence monitoring
- Satellite status indicators
- Live mission log

### Interactive Map
- 6 spill scenarios: Natural, Culprit, Internal, Collision, Fire, Weather
- Vessel tracking and identification
- STS transfer visualization
- Dynamic legend and overlays

### Satellite Scanner
- SAR satellite simulation
- AIS data integration
- Triboelectric sensing
- UAV deployment tracking
- Raw telemetry data

### Alert System
- AI voice alerts with Speech Synthesis
- Continuous alarm system
- Customizable alert scenarios

### Analysis
- Oil spread trend visualization
- Spill type distribution charts
- Response time tracking
- Affected area monitoring

### Settings
- 6 Languages: English, Hindi, Spanish, French, Arabic, Chinese
- Dark/Light theme toggle
- Notification preferences
